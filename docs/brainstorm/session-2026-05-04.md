## Decisions

### D1 — Startup approach: manual uvicorn trước, systemd sau
- **Decision:** Chạy thủ công qua uvicorn để verify trước, sau đó mới setup systemd service.
- **Rationale:** Dễ debug, thấy output trực tiếp trên terminal.

### D2 — Virtual environment
- **Decision:** Dùng `python3 -m venv venv` trong `backend/`.
- **Rationale:** Tránh conflict với system Python, sạch sẽ hơn.

### D3 — Serial port default
- **Decision:** Default config là `/dev/ttyUSB0`, 115200 baud.
- **Rationale:** `config.py` hard-code, có thể override bằng `.env` file nếu port khác.

## Startup Checklist (trên Pi5)

```bash
# 1. SSH vào Pi
ssh pi@10.0.0.1

# 2. Vào backend directory
cd ~/mesh_server/mesh_pi5_server/backend

# 3. Tạo + activate virtual environment
python3 -m venv venv
source venv/bin/activate

# 4. Cài dependencies
pip install -e .

# 5. Kiểm tra serial port
ls /dev/ttyUSB* /dev/ttyACM* 2>/dev/null

# 6. Khởi động server
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 7. Test (từ terminal khác)
curl http://10.0.0.1:8000/
```
