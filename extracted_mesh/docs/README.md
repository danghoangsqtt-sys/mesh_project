## Các tính năng chính của hệ thống
1. Bản đồ Chiến thuật Ngoại tuyến (MapLibre PMTiles)
2. Truyền nhận dữ liệu Real-time (LoRa 433MHz -> USB Serial -> WebSocket)
3. Hàng rào Điện tử (Geofencing) & Tìm đường AI (A* Pathfinding)
4. Hệ thống Cảnh báo Thông minh Đa ngôn ngữ (Vitals, Connection, Power)
5. Cập nhật Firmware Không dây tầm xa (OTA via LoRa)
