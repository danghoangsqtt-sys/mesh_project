# Task 1.2 — Binary Protocol Layer (comm/)

## Objective
Implement packet parser, CRC16-CCITT, và frame extractor tương thích 100% với firmware C struct của Mesh LilyGo. Đảm bảo parse chính xác gói tin 40-byte SoldierPacket và hỗ trợ xử lý luồng byte serial thực tế.

## Paths
- `app/src/main/java/com/meshcommand/app/comm/CRC16.kt`
- `app/src/main/java/com/meshcommand/app/comm/SoldierPacket.kt`
- `app/src/main/java/com/meshcommand/app/comm/PacketParser.kt`
- `app/src/main/java/com/meshcommand/app/comm/FrameExtractor.kt`
- `app/src/test/java/com/meshcommand/app/comm/PacketParserTest.kt`
- `app/src/test/java/com/meshcommand/app/comm/CRC16Test.kt`

## File-Level Plan
1. **CRC16.kt**:
   - Implement hàm tính toán CRC16-CCITT (polynomial 0x1021, initial 0xFFFF) tương tự như firmware. Hàm nhận vào ByteArray và trả về Int (UInt16).
2. **SoldierPacket.kt**:
   - Định nghĩa data class `SoldierPacket` chứa các trường tương ứng với struct C (nodeId, lat, lon, HR, SpO2, temp, battery, status, etc.).
3. **PacketParser.kt**:
   - Class chứa hàm `parse(bytes: ByteArray): SoldierPacket` dùng ByteBuffer với order `LITTLE_ENDIAN` để đọc các giá trị.
   - Chứa hàm `build(packet: SoldierPacket): ByteArray` để serialize dữ liệu gửi xuống gateway.
4. **FrameExtractor.kt**:
   - Class stateful nhận chuỗi byte stream từ USB.
   - Tìm header `0xAA`, đọc đủ 40 bytes, verify footer `0x55` và check CRC.
   - Xử lý tin nhắn sideband dạng ASCII từ gateway như `GW_GPS:lat,lon\n`.
5. **Unit Tests**:
   - Viết test với dữ liệu byte raw giả lập để đảm bảo endianness và tính toán CRC chính xác.

## Best Practices
- Sử dụng `java.nio.ByteBuffer` cho hiệu năng parse binary cao nhất.
- Chú ý LITTLE_ENDIAN vì vi điều khiển ESP32 sử dụng little endian.
- Unit testing là bắt buộc đối với logic parse binary.
