# Task 1.6 — MapLibre Offline Map

## Objective
Tích hợp MapLibre Native SDK vào Compose UI, hỗ trợ load MBTiles offline từ `context.filesDir/maps/`, custom military style JSON, soldier/gateway markers theo trạng thái, và camera controls.

## Paths
- `app/src/main/java/com/meshcommand/app/ui/map/MapScreen.kt`
- `app/src/main/java/com/meshcommand/app/ui/map/MapViewModel.kt`
- `app/src/main/assets/map_style_military.json`

## File-Level Plan
1. **map_style_military.json** — MapLibre style JSON với military color scheme (dark green background, high contrast roads/water, subdued labels). Fallback style khi không có MBTiles — sử dụng blank background với grid lines.

2. **MapViewModel.kt** — ViewModel expose `soldierPositions: StateFlow<List<SoldierEntity>>`, `gatewayPosition: StateFlow<Pair<Double,Double>?>`, `selectedSoldier: StateFlow<Int?>`. Collect từ `SoldierRepository`. Hàm `selectSoldier(nodeId)` và `centerOnSoldier(nodeId)`.

3. **MapScreen.kt** — Composable sử dụng `AndroidView` để embed `MapView` từ MapLibre. Tạo markers cho từng soldier với icon/color theo alertLevel:
   - Level 0 (OK) → Green circle
   - Level 1 (WARN) → Yellow triangle
   - Level 2 (CRIT) → Red pulsing diamond
   - Offline → Gray circle
   Gateway marker riêng biệt (Blue star). Tap marker → callback lên ViewModel. Camera: center vào tọa độ trung bình lần đầu.

## Best Practices
- `AndroidView` trong Compose cho MapLibre (chưa có Compose wrapper native).
- `remember { MapView(context) }` để tránh recreate khi recompose.
- Dispose lifecycle đúng cách qua `DisposableEffect`.
- Symbol layer cho markers thay vì native Marker API (deprecated).
