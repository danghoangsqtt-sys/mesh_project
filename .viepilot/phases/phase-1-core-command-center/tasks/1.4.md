# Task 1.4 — ForegroundService

## Objective
Implement `MeshForegroundService` — Android ForegroundService giữ kết nối USB Serial liên tục ngay cả khi app ở background. Service quản lý lifecycle của `UsbSerialManager`, forward serial data qua `SharedFlow` cho Repository layer, và hiển thị persistent notification với trạng thái kết nối.

## Paths
- `app/src/main/java/com/meshcommand/app/service/MeshForegroundService.kt`
- `app/src/main/java/com/meshcommand/app/di/AppModule.kt`
- `app/src/main/AndroidManifest.xml` (modify — add service declaration)

## File-Level Plan
1. **MeshForegroundService.kt**:
   - Kế thừa `Service()`, annotate `@AndroidEntryPoint` cho Hilt injection.
   - `onCreate()` — Khởi tạo `UsbSerialManager`, notification channel, register USB BroadcastReceiver.
   - `onStartCommand()` — Bắt đầu foreground notification, auto-connect USB, collect serial data flow → emit qua `SharedFlow`.
   - `onDestroy()` — Disconnect USB, unregister receiver, cleanup coroutine scope.
   - `onBind()` — Return `LocalBinder` cho Activity bind.
   - `LocalBinder` inner class — expose `packetFlow: SharedFlow<SoldierPacket>`, `gatewayGpsFlow: SharedFlow<Pair<Double,Double>>`, `connectionState: StateFlow<ConnectionState>`, `sendCommand()`.
   - Notification: tạo `NotificationChannel`, build persistent notification hiển thị "Connected to [device]" / "Disconnected" / "Error", cập nhật notification khi state thay đổi.
   - `foregroundServiceType = "connectedDevice"`.

2. **AppModule.kt**:
   - Hilt `@Module` cung cấp singleton dependencies nếu cần.

3. **AndroidManifest.xml**:
   - Thêm `<service>` declaration cho `MeshForegroundService` với `foregroundServiceType="connectedDevice"`.

## Best Practices
- Service giữ `CoroutineScope(SupervisorJob() + Dispatchers.IO)`, cancel khi onDestroy.
- SharedFlow thay vì LiveData để decouple service khỏi lifecycle UI.
- Notification channel tạo 1 lần trong onCreate, không recreate.
- Sử dụng `ServiceCompat.startForeground()` cho Android 14+ compatibility.
