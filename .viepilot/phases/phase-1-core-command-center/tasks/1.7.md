# Task 1.7 — Tactical Panel UI (Compose)

## Objective
Xây dựng bảng điều khiển chiến thuật bên phải màn hình dưới dạng Jetpack Compose, bao gồm Connection Bar, Node Table, Command Panel, Event Log, và Status Bar. Giao diện nhất quán với military green theme của desktop app hiện tại.

## Paths
- `app/src/main/java/com/meshcommand/app/ui/theme/MeshTheme.kt`
- `app/src/main/java/com/meshcommand/app/ui/tactical/TacticalViewModel.kt`
- `app/src/main/java/com/meshcommand/app/ui/tactical/ConnectionBar.kt`
- `app/src/main/java/com/meshcommand/app/ui/tactical/NodeTable.kt`
- `app/src/main/java/com/meshcommand/app/ui/tactical/CommandPanel.kt`
- `app/src/main/java/com/meshcommand/app/ui/tactical/EventLog.kt`
- `app/src/main/java/com/meshcommand/app/ui/tactical/StatusBar.kt`
- `app/src/main/java/com/meshcommand/app/ui/tactical/TacticalPanel.kt`

## File-Level Plan
1. **MeshTheme.kt** — Military color palette constants, typography, composable theme wrapper.
2. **TacticalViewModel.kt** — `@HiltViewModel`, expose soldiers Flow, events Flow, connection state. Commands: sendMessage, selectSoldier.
3. **ConnectionBar.kt** — Compact row: status dot (green/red), device name, Connect/Disconnect button.
4. **NodeTable.kt** — `LazyColumn` soldier rows: ID, Status (color dot), HR, SpO2, Temp, Battery. Tap row → callback.
5. **CommandPanel.kt** — Message input, target dropdown, Send button. Military styled.
6. **EventLog.kt** — `LazyColumn` reverse-chronological events with severity color coding.
7. **StatusBar.kt** — Active nodes count, last RX timestamp, GPS fix indicator.
8. **TacticalPanel.kt** — Assembles all sub-components into vertical Column.
