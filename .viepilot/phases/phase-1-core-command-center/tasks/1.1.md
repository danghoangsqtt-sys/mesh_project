# Task 1.1 — Project Setup & Build System

## Objective
Khởi tạo project Android Studio với Kotlin, Jetpack Compose, Hilt DI, và Gradle Version Catalog. Thiết lập cấu hình cơ bản cho ứng dụng (landscape-only, USB permissions) và color scheme military green.

## Paths
- `build.gradle.kts` (Project level)
- `app/build.gradle.kts` (App level)
- `gradle/libs.versions.toml`
- `app/src/main/AndroidManifest.xml`
- `app/src/main/java/com/meshcommand/app/MeshCommandApp.kt`
- `app/src/main/java/com/meshcommand/app/ui/theme/Color.kt`
- `app/src/main/java/com/meshcommand/app/ui/theme/Theme.kt`
- `app/src/main/res/values/strings.xml`

## File-Level Plan
1. **gradle/libs.versions.toml**:
   - Khai báo các version và libraries: AndroidX Core, Compose BOM, Lifecycle, Activity Compose, Hilt, MapLibre, UsbSerialForAndroid, Room.
2. **build.gradle.kts** (Project):
   - Config plugins (Android Application, Kotlin Android, Hilt).
3. **app/build.gradle.kts**:
   - Apply plugins. Config `namespace = "com.meshcommand.app"`, `minSdk = 29`.
   - Enable `buildFeatures { compose = true }`.
   - Cấu hình dependencies bằng catalog.
4. **app/src/main/AndroidManifest.xml**:
   - Thêm `<uses-feature android:name="android.hardware.usb.host" />`.
   - `<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />`.
   - `<uses-permission android:name="android.permission.FOREGROUND_SERVICE_CONNECTED_DEVICE" />`.
   - Config `MainActivity` với `android:screenOrientation="landscape"`.
   - Declare application class `MeshCommandApp`.
5. **app/src/main/java/com/meshcommand/app/MeshCommandApp.kt**:
   - Khởi tạo Application class với `@HiltAndroidApp`.
6. **app/src/main/java/com/meshcommand/app/ui/theme/Color.kt** & **Theme.kt**:
   - Set up custom Material 3 ColorScheme với tone màu Military Green.

## Best Practices
- Sử dụng Gradle Version Catalog để quản lý dependencies đồng bộ.
- Hilt setup chuẩn theo Google guidelines.
- Material 3 theming chuẩn, tách biệt file colors và theme.
