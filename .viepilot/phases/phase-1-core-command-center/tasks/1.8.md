# Task 1.8 — Main Activity & Layout Assembly

## Objective
Ghép nối MapScreen + TacticalPanel vào split-screen layout (65/35), wire Service → Repository → ViewModel → Compose. Landscape-only đã có sẵn. Bind ForegroundService, start coroutine timeout loop, và forward SharedFlow data vào Repository.

## Paths
- `app/src/main/java/com/meshcommand/app/MainActivity.kt` (rewrite)

## File-Level Plan
1. **MainActivity.kt** — Rewrite hoàn toàn:
   - `@AndroidEntryPoint` activity
   - `onCreate`: start `MeshForegroundService`, bind service, set Compose content
   - `onDestroy`: unbind service
   - Compose layout: `Row` → `MapScreen(weight 0.65f)` + `TacticalPanel(weight 0.35f)`
   - Wire ViewModels: `MapViewModel`, `TacticalViewModel` via `hiltViewModel()`
   - Service binding: `ServiceConnection` callback → collect `packetFlow` → `repository.processPacket()`
   - Timeout coroutine: periodic `repository.checkTimeouts()` mỗi 5 giây
   - Gateway GPS forwarding: `gatewayGpsFlow` → `mapViewModel.updateGatewayPosition()`
   - Soldier selection bridge: TacticalPanel tap → MapViewModel.centerOnSoldier()
