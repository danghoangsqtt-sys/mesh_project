# Task 2.2 — WiFi AP Communication

## Objective
Thêm kênh kết nối WiFi AP song song với USB OTG. Gateway phát WiFi AP, app kết nối qua TCP socket và nhận cùng giao thức packet 40-byte.

## Paths
- `app/src/main/java/com/meshcommand/app/comm/WifiCommManager.kt`
- `app/src/main/java/com/meshcommand/app/comm/ConnectionState.kt` (modify — add WiFi state)
- `app/src/main/java/com/meshcommand/app/service/MeshForegroundService.kt` (modify — add WiFi channel)
- `app/src/main/AndroidManifest.xml` (modify — add WiFi permissions)
- `app/src/main/java/com/meshcommand/app/di/AppModule.kt` (modify — provide WifiCommManager)

## File-Level Plan
1. **WifiCommManager.kt** — TCP socket client using `kotlinx.coroutines`:
   - `connect(host: String, port: Int)` → open socket, start read loop
   - `disconnect()` → close socket
   - `packetFlow: SharedFlow<SoldierPacket>` — parsed packets from TCP stream
   - `connectionState: StateFlow<ConnectionState>` — WiFi-specific state
   - Uses `BinaryProtocol.FrameExtractor` to parse byte stream
2. **ConnectionState.kt** — Add `WifiConnected(ssid)` variant
3. **MeshForegroundService.kt** — Accept WiFi packets alongside USB, merge into single packetFlow
4. **AndroidManifest.xml** — Add `ACCESS_WIFI_STATE`, `CHANGE_WIFI_STATE`, `INTERNET` permissions
