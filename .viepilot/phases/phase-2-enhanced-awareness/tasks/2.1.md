# Task 2.1 — Path Trail

## Objective
Vẽ polyline đường di chuyển (GPS trail) cho mỗi soldier trên map. Lưu lịch sử vị trí vào `position_history` table. Hỗ trợ filter thời gian (30 phút / 1 giờ / toàn bộ). Màu trail theo team hoặc theo node.

## Paths
- `app/src/main/java/com/meshcommand/app/data/entity/PositionHistoryEntity.kt`
- `app/src/main/java/com/meshcommand/app/data/dao/PositionHistoryDao.kt`
- `app/src/main/java/com/meshcommand/app/data/MeshDatabase.kt` (modify — add entity + DAO + bump version)
- `app/src/main/java/com/meshcommand/app/data/SoldierRepository.kt` (modify — save position history on packet)
- `app/src/main/java/com/meshcommand/app/ui/map/MapScreen.kt` (modify — draw polylines)
- `app/src/main/java/com/meshcommand/app/ui/map/MapViewModel.kt` (modify — expose trail data + time filter)

## File-Level Plan
1. **PositionHistoryEntity.kt** — Room `@Entity(tableName="position_history")` with nodeId, lat, lon, heading, timestampMs. Foreign key to soldiers.
2. **PositionHistoryDao.kt** — `@Insert`, `getTrailForNode(nodeId, sinceMs): Flow<List>`, `deleteOlderThan(thresholdMs)`.
3. **MeshDatabase.kt** — Add PositionHistoryEntity to entities array, bump version to 2 with fallbackToDestructiveMigration.
4. **SoldierRepository.kt** — In `processPacket()`, also insert `PositionHistoryEntity` row after upsert soldier.
5. **MapViewModel.kt** — Add `trailDurationMs: StateFlow<Long>` (default 30 min), `allTrails: StateFlow<Map<Int, List<LatLng>>>`, `setTrailDuration(ms)`.
6. **MapScreen.kt** — After markers, draw polylines per soldier using `map.addPolyline()`. Color by alert status or a fixed palette per nodeId.
