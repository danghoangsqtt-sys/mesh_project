# Task 8.1: Interactive Geofence Drawing

## Objective
Xây dựng tính năng cho phép chỉ huy vẽ các vùng chiến thuật (Geofence) trực tiếp trên MapLibre. 
Khi bật chế độ "Draw Geofence", người dùng click vào bản đồ để tạo các điểm chốt của Polygon.
Vùng Polygon này (Danger/Safe Zone) sẽ được lưu xuống `Room Database` (bảng `geofences`) khi hoàn tất.

## Paths
- `app/src/main/java/com/meshcommand/app/ui/map/MapScreen.kt`
- `app/src/main/java/com/meshcommand/app/ui/map/MapViewModel.kt`
- `app/src/main/java/com/meshcommand/app/data/entity/GeofenceEntity.kt` (Kiểm tra/Tạo)
- `app/src/main/java/com/meshcommand/app/data/dao/GeofenceDao.kt` (Kiểm tra/Tạo)

## File-Level Plan

1. **Database / Entity (`GeofenceEntity.kt`, `GeofenceDao.kt`)**:
   - Nếu chưa có, tạo `GeofenceEntity` lưu id, name, type (SAFE, DANGER), polygonJson.
   - Thêm các hàm `insert`, `getAll`, `delete` vào `GeofenceDao`.

2. **`MapViewModel.kt`**:
   - Thêm State để kiểm soát: `isDrawingMode` (Boolean), `currentDrawPoints` (List<Point>), `savedGeofences` (List<GeofenceEntity>).
   - Hàm `onMapClick(lat: Double, lon: Double)`: nếu đang vẽ thì add điểm.
   - Hàm `finishDrawing(name: String, type: String)`: lưu xuống Database và tắt mode vẽ.

3. **`MapScreen.kt`**:
   - Tích hợp `GeoJsonSource` và `FillLayer`, `LineLayer` để hiển thị `currentDrawPoints` (vùng nháp đang vẽ) và `savedGeofences` (vùng đã lưu).
   - Đăng ký `OnMapClickListener` vào MapLibre, truyền tọa độ vào `ViewModel.onMapClick`.
   - Thêm UI Overlay (Nút Toggle Draw Mode, Cancel, Save).

## Verification
- Chạy App trên máy/simulator ảo.
- Bấm nút "Draw", click bản đồ tạo ít nhất 3 điểm -> Sinh ra một mảng Polygon màu mờ (FillLayer).
- Bấm "Save" -> Polygon được lưu thành công, hiển thị cố định trên Map.
