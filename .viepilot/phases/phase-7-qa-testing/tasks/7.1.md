# Task 7.1: Unit Testing & Logic

## Objective
Thiết lập bộ Unit Test theo tiêu chuẩn (sử dụng JUnit 5, MockK, Coroutines Test) cho các thành phần tính toán cốt lõi của ứng dụng Mesh Android để đảm bảo độ tin cậy cấp quân sự.

## Paths
- `app/build.gradle.kts` (kiểm tra/thêm dependencies test nếu chưa đủ).
- `app/src/test/java/com/meshcommand/app/data/parser/PacketParserTest.kt`
- `app/src/test/java/com/meshcommand/app/domain/tactical/TacticalCalculatorTest.kt`
- `app/src/test/java/com/meshcommand/app/domain/tactical/GeofenceCheckerTest.kt`

## File-Level Plan

1. **Dependencies (`build.gradle.kts`)**:
   - Xác nhận có `junit-jupiter`, `mockk`, `kotlinx-coroutines-test`, `truth`.
   - Bật test tasks trong Gradle.

2. **`PacketParserTest`**:
   - Giả lập các gói byte hex từ LoRa Gateway (Frame hợp lệ, Frame lỗi CRC, Frame không đủ độ dài).
   - Xác minh `PacketParser.parse()` trả về object đúng data.

3. **`TacticalCalculatorTest`**:
   - Viết test tính toán khoảng cách (Distance) và phương vị (Bearing) giữa 2 tọa độ GPS (Gateway và Soldier).
   - Kiểm tra các trường hợp viền (cùng tọa độ, lỗi null).

4. **`GeofenceCheckerTest`**:
   - Viết test tính toán điểm nằm trong hay ngoài Polygon (Ray-casting algorithm).
   - Sẽ chuẩn bị sẵn class `GeofenceChecker` (kết hợp với Phase 8 Geofencing sắp làm) để test trước logic Point-in-Polygon.

## Verification
- Chạy lệnh: `./gradlew testDebugUnitTest`
- Đảm bảo tất cả các test cases pass 100%.
- Không có lỗi biên dịch.
