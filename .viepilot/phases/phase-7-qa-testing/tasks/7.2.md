# Task 7.2: Mock Serial & UI Testing

## Objective
Hoàn thiện khả năng kiểm thử giao diện bằng Jetpack Compose UI Tests, đặc biệt là các Component phức tạp như bảng danh sách Node và các Panel hiển thị chiến thuật.
Mục tiêu là mô phỏng luồng dữ liệu (Mock data) đẩy vào UI và kiểm chứng tính phản hồi của Compose.

## Paths
- `app/src/androidTest/java/com/meshcommand/app/ui/tactical/NodeTableTest.kt`
- `app/src/androidTest/java/com/meshcommand/app/ui/tactical/CommandPanelTest.kt`

## File-Level Plan

1. **`NodeTableTest.kt`**:
   - Sử dụng `createComposeRule()`.
   - Setup dữ liệu mock gồm 2 Soldier Nodes giả lập.
   - Gọi Compose component `NodeTable(nodes = mockData, ...)`.
   - Kiểm tra `onNodeWithText` xem ID, Team hoặc Status (ví dụ: "Alpha", "101") có hiển thị đúng không.
   - Đảm bảo danh sách Node không bị crash.

2. **`CommandPanelTest.kt`**:
   - Render `CommandPanel`.
   - Kiểm tra xem TextField và Button gửi lệnh có tồn tại bằng các Matcher của Jetpack Compose Test.
   - Thử click nút "Send" và verify Callback có được trigger hay không.
