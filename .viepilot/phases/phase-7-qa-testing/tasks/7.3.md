# Task 7.3: Integration Test Suite

## Objective
Viết bài test tích hợp (End-to-End data flow test) để mô phỏng toàn bộ luồng xử lý thực tế: từ khâu nhận dữ liệu thô (đã được parse) -> cập nhật thông qua `SoldierRepository` -> kiểm chứng trạng thái dữ liệu thay đổi trên UI StateFlow. Điều này đảm bảo rằng không có điểm nghẽn hoặc lỗi dữ liệu trong kiến trúc Room Database và StateFlow.

## Paths
- `app/src/androidTest/java/com/meshcommand/app/integration/DataFlowIntegrationTest.kt`

## File-Level Plan

1. **`DataFlowIntegrationTest.kt`**:
   - Sử dụng Room in-memory database để tạo một test environment an toàn không ảnh hưởng app thật.
   - Khởi tạo DAO (`SoldierDao`) và `SoldierRepository`.
   - Mô phỏng quá trình: Tạo một đối tượng `SoldierEntity` giả (như luồng từ `FrameExtractor` trả về).
   - Gọi hàm `repository.updateSoldierData(soldier)`.
   - Thu thập (collect) luồng `repository.getAllSoldiersStream()` bằng Turbine hoặc trực tiếp thu thập giá trị đầu tiên (first).
   - Kiểm chứng (Assert) xem dữ liệu mock có xuất hiện trong danh sách lấy từ DB ra không, khớp Node ID và các thông số cảm biến.
