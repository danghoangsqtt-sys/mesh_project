# Task 6.2: Refactor UI Layout to Node Table

## Objective
Replace the card-based layout with a `QTableWidget` to match the design language of the referenced `Mesh_Manager_Completed` project.

## Paths
- `server/ui_components.py`
- `server/main_app.py`

## Implementation Plan
1. In `ui_components.py`, create a `NodeTableWidget` (inheriting from `QTableWidget`) with columns: ID, Team, Position, HR, SpO2, Temp, Battery, Alert Level.
2. In `main_app.py`, remove the scroll area of `TeamGroupWidget`s and replace it with the `NodeTableWidget`.
3. Update `on_data_updated` to populate rows in the `QTableWidget` instead of updating individual card widgets.
4. Style the `QTableWidget` with the new Military Green colors and ensure text is white and legible.
